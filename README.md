[video demo](https://youtube.com/shorts/rzfIFHaLiHA?feature=share)

This uses WeAct BlackPill (STM32F411), a bunch of resistors and 4 piezo sensors for its electronics.

The drum part is a 5mm elastic rubber (30$ for 0.1m2, damn that's expensive), metal squares and foam pads made from stick-on wall material. 
The drum "sandwhich" goes like this: rubber->metal->piezo/foam pads.
